# 부팅 계약 — 128개 엔드포인트가 실제로 존재하는지 (완료)

이 서비스의 전부는 `main.py`의 모듈 수준 표 하나에 달려 있습니다.
`SCRIPT_ROUTES`가 엔드포인트 경로 120개를 스크립트 파일 120개에 대응시키고,
루프가 그 쌍을 `register_script_route()`에 넘깁니다.

**그 루프는 아무것도 확인하지 않습니다.**

이름이 바뀐 스크립트, 지워진 스크립트, 애초에 없던 스크립트도 라우트로는
아무 불평 없이 등록됩니다. 엔드포인트는 존재하고, 응답하고, HTTP 400에 파이썬의
`can't open file`을 담아 돌려줍니다 — 단 **그 분석 하나를 누른 사람에게만,
프로덕션에서만.** 경로가 중복된 경우도 같습니다(Starlette는 등록 순서로
매칭하므로 두 번째 등록은 도달 불가능한 죽은 코드입니다). `requirements.txt`가
설치하지 않는 패키지를 import하는 스크립트도 같습니다.

이 중 **어느 것도 부팅 실패가 아니라는 게 핵심입니다.** 컨테이너는 정상으로
올라오고 아무 말도 하지 않습니다. 그래서 부팅 검사가 필요합니다.

## 무엇을 확인하는가

`scripts/check_startup.py`는 `main.py`를 다시 파싱하지 않습니다. **실제 앱을
import하고 앱에게 무엇을 서비스하는지 묻습니다** — `main.app`의 OpenAPI
스키마입니다. 검사 대상인 소스로부터 라우트 표를 다시 유도하는 검사는 구조상
자기 자신과 항상 일치합니다.

| # | 확인 | 못 잡으면 |
| --- | --- | --- |
| 1 | `main`이 import된다 (라우터·레지스트리·120개 등록 전부) | Cloud Run이 ready에 도달하지 못함 |
| 2 | 표의 120개 경로가 전부 서비스되고, 중복 경로·중복 스크립트가 없다 | 두 번째 등록이 죽은 코드 |
| 3 | 등록된 스크립트가 전부 디스크에 있고 컴파일된다 | 클릭 시점의 400 |
| 4 | import 시점에 쓰이는 모든 서드파티 모듈이 핀으로 고정돼 있다 | 이미지에 없는 패키지 → 클릭 시점의 400 |
| 5 | 마운트한 라우터 6개가 실제로 엔드포인트를 기여했다 | `include_router()`가 빈 라우터를 조용히 삼킴 |
| 6 | 루트의 `.py` 중 배선 안 된 것이 없다 | 추가했지만 아무도 부를 수 없는 스크립트 |
| 7 | 실패한 스크립트의 **자기 메시지**가 400으로 사용자에게 닿는다 | 트레이스백 — 사용자가 할 수 있는 게 없음 |
| 8 | 128개 엔드포인트 앞에 선 rate limiter가 세고, `/health`는 면제한다 | 정상 트래픽을 429로 막거나, readiness probe를 막아 서비스를 내림 |

7·8은 `fastapi.testclient` 대신 ASGI 앱을 손으로 호출합니다. TestClient는
httpx가 필요하고 그건 이 이미지에 없는 개발 의존성입니다 — **코드가 도는 곳에서
돌 수 없는 검사는 검사가 아닙니다.**

4번에는 허용 목록이 하나 있습니다. `mpl_toolkits`, `pydantic`, `starlette`는
자기 핀이 아니라 다른 핀을 타고 옵니다(각각 matplotlib 휠 안, fastapi의 무조건
의존성 둘 — `importlib.metadata.requires('fastapi')`와 휠 내용으로 확인).
항목마다 **무엇이 데려오는지**를 적어 둔 이유는, 새로 생긴 미고정 import가 그
사이에 숨지 못하게 하는 것입니다.

## 초록색이 무언가를 뜻하게 만들기

위의 22개는 전부 이 스크립트가 통제하지 않는 코드에 대한 주장입니다. 빨간색이
가능하지 않으면 초록색은 아무 뜻이 없습니다.

```
python scripts/check_startup.py             # 몇 초
python scripts/check_startup.py --prove     # ~2분
```

`--prove`는 백엔드를 임시 복사본으로 떠서 위의 열한 가지를 하나씩 실제로
망가뜨리고 — 스크립트를 지우고, 경로를 중복시키고, 미고정 패키지를 import하고,
라우터 마운트를 빼고, limiter가 세는 줄을 지우고 — **해당 줄이 빨개지는 것을
요구합니다.** 복사본은 버려지고 작업 트리는 건드리지 않습니다.

```

```
